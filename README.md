# Survivor.js - 倖存者戰士

一個使用 Phaser.js 製作的類倖存者 (Survivor-like) 綊頁遊戲 Demo，復刻《小女巫倖存者》的核心割草體驗。

## 遊戲特色

- **自動戰鬥**：玩家負責走位避開碰撞，盔甲戰士自動鎖定範圍內最近敵人並揮劍發射魔法彈
- **割草感**：高頻率的敵人生成與流暢的擊殺回饋
- **成長循環**：擊殺敵人 → 掉落經驗球 → 升級 → 三選一隨機技能強化
- **連殺獎勵**：一次擊殺多隻重疊怪物可獲得攻擊速度加成
- **波次系統**：每 60 秒一波，每 5 波出現 Boss

## 敵人類型

| 類型 | 特性 | 出現時間 |
|------|------|----------|
| 普通型 | 紅色圓形怪物 | 遊戲開始 |
| 快速型 | 綠色小型怪物，速度快 | 30秒後 |
| 坦克型 | 灰色大型怪物，高血量 | 60秒後 |
| 遠程型 | 紫色怪物，會發射子彈 | 45秒後 |
| Boss | 深紅色大型怪物，皇冠標記 | 每5波 |

## 天賦系統

升級時隨機提供 3 項強化選項：

- ❤️ **生命強化**：最大生命值 +20
- 💨 **疾風步**：移動速度 +30
- 🧲 **磁力手套**：拾取範圍 +30
- 👁️ **鷹眼**：攻擊範圍 +50
- ⚡ **急速射擊**：射擊間隔 -0.08秒
- ✨ **魔力增幅**：傷害 +1
- 🚀 **子彈加速**：子彈速度 +100
- 🎯 **多重射擊**：同時發射 +1 顆子彈

## 操作方式

- **WASD / 方向鍵**：移動角色
- **ESC / P**：暫停遊戲

## 如何運行

1. 安裝依賴（需要 Node.js）：
```bash
npx serve
```

2. 或使用 Python：
```bash
python -m http.server 8080
```

3. 在瀏覽器中打開 `http://localhost:5566`（或 `http://localhost:8080`）

## 技術架構

- **引擎**：Phaser.js 3.70.0
- **渲染**：Canvas / WebGL（自動選擇）
- **音效**：Web Audio API 合成音效
- **存檔**：localStorage 儲存歷史紀錄
